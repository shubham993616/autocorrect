# 2-minute demonstration script

1. **Introduce the project:** “This is my Autocorrect Tool, a Python application that corrects common English spelling mistakes.”
2. **Explain the tools:** “I used Streamlit for the interface and the `autocorrect` library for spelling correction.”
3. **Show the input:** Enter `I hav a beautifull gardn.`
4. Click **Correct Text** and show the result. The exact result may vary, so describe what the app actually displays.
5. **Show a second test:** Enter a correctly spelled sentence, such as `Today is a sunny day.`
6. **Show empty input:** Clear the text box and click the button to demonstrate validation.
7. **Explain the limitation:** “This version focuses on spelling and is not a complete grammar or context-aware correction system.”
